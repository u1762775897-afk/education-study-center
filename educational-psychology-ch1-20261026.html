第一章 · 思维导图层级

一、研究对象及内容：研究对象 → 研究内容（五要素、三过程）→ 学科性质 → 作用 → 研究原则

二、发展概况：发展过程（初创、发展、成熟、完善）→ 研究趋势

记忆：五要素「生师内媒环」；三过程「学、教、评反」；四阶段「20前、20—50、60—70、80后」。

知识点与标准答案

1. 研究对象

答案：学校教育情境中学与教的基本心理规律。

易混 / 考点：注意：不是研究一切心理现象，也不只研究学生。

2. 五要素

答案：学生、教师、教学内容、教学媒体、教学环境。

易混 / 考点：学生是学习主体；教师起主导作用；教学内容是有意传递的主要信息；媒体是传递信息的载体；环境包括物质环境和社会环境。

3. 三个过程

答案：学习过程、教学过程、评价与反思过程。

易混 / 考点：学习过程是核心；评价与反思贯穿学与教。

4. 学科性质

答案：教育心理学是心理学与教育学交叉的学科，具有理论性与应用性，通常归为应用心理学领域。

易混 / 考点：不同教材对性质的具体表述可能不同。

5. 学科作用

答案：帮助教师准确了解问题；为实际教学提供科学理论指导；帮助教师预测并干预学生行为；帮助教师结合教学实际开展研究。

易混 / 考点：常见口诀：了解—指导—预测干预—研究。

6. 研究原则

答案：客观性、教育性、发展性、理论联系实际、系统性等。

易混 / 考点：教材版本可能增减原则；教育性强调研究不得损害学生身心健康。

7. 初创时期（20世纪20年代以前）

答案：1903年桑代克出版《教育心理学》，常作为教育心理学独立学科诞生的标志；1904—1913年扩展为三卷本《教育心理学大纲》。

易混 / 考点：易混：1903年桑代克；1879年冯特建立实验心理学实验室，是科学心理学诞生的标志。

8. 发展时期（20世纪20年代至50年代末）

答案：学科内容扩展，吸收行为主义、测量、学习理论等研究，体系尚未统一。

易混 / 考点：重发展、未统一。

9. 成熟时期（20世纪60年代至70年代末）

答案：内容趋于集中，注重教育实际；认知心理学及教学过程研究影响增强。

易混 / 考点：重教学实践。

10. 完善时期（20世纪80年代以后）

答案：理论体系进一步完善，认知研究、建构主义、社会文化取向、学习策略与教育技术研究不断发展。

易混 / 考点：注意80年代以后，不是20世纪以后。

11. 研究趋势

答案：更加关注学习者主体性、认知与社会文化情境、真实课堂、个体差异、技术支持学习、跨学科及多方法研究。

易混 / 考点：本项为通用概括，具体考试表述以所用教材为准。
